# SHAKTHI - Empowering Women Athletes

This repository contains the source code and configuration for **SHAKTHI**, an AI-powered platform for women athletes.

## Repository Layout
- **[project/](file:///c:/Users/shaya/Downloads/SHAKTHI-AI/project/)**: The main web application frontend and backend configurations.
  - See the detailed application documentation in **[project/README.md](file:///c:/Users/shaya/Downloads/SHAKTHI-AI/project/README.md)**.

## Getting Started Quickly

1. Navigate to the `project` folder:
   ```bash
   cd project
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
